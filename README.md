# Reliability of the timed Brazilian Adductor Performance Test and comparison between male football players with and without a past-season groin injury
This repo contains data and code for the project titled "Reliability of the timed Brazilian Adductor Performance Test and comparison between male football players with and without a past-season groin injury"

Link to paper: *[DOI link to be added]*

📂 Files

Contains all the R scripts for the project:
- `reliability_outcomes.R`: Test-retest reliability analysis (ICC, SEM, MDC, CV), repeated measures correlation, and Bland-Altman plots.
- `bapt_cs.R`: Descriptive statistics and linear mixed-effects models comparing male football players with and without a past-season groin injury.
- `sensitivity_cs.R`: Contains sensitivity analyses.

Includes the datasets required to run the analyses:
- `reliability_bapt.xlsx`: Dataset used for the test-retest reliability analysis.
- `basic_ds.xlsx`: Dataset used for baseline descriptions and group comparisons.
